# IPL Match Analysis Dashboard

A simple and interactive IPL Match Analysis Dashboard built using **Python, Pandas, and Streamlit**.

This project analyzes IPL match data and presents useful insights through an interactive dashboard.

## Features

- Upload IPL match data using a CSV file
- Preview the uploaded dataset
- View dataset information
- Check missing values
- View overall IPL statistics
- Analyze team performance
- Select a team and view:
  - Matches played
  - Matches won
  - Matches lost
  - Win percentage
  - Matches played by season
- Analyze toss results
- Compare toss winners with match winners
- Analyze toss decisions (Bat vs Field)
- Analyze matches by venue
- Find the most used venues
- Find top Player of the Match winners
- Explore matches by season and team
- Clean historical team names before analysis

## Technologies Used

- Python
- Pandas
- Streamlit
